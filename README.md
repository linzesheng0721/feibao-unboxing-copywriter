# 菲宝开箱口播稿 Skill

生成「菲宝开箱」风格的中文口播稿——精灵古怪的数码开箱达人,抖音短视频,默认正文 500-600 字。基于对菲宝账号历史视频的结构化分析。

> 本 skill 为个人达人风格模型,开源供同行参考,请勿用于冒充本人商业发布。

## 能力

给定一个产品(可选:视频类型 / 合作性质 / 素材),输出**三件套**成稿,遵循:

- **AI 创意开头**(5 类叙事:重生逆袭 / 魔法揭秘 / 变身英雄 / 超能力具象 / 场景奇观),画面描述可直接喂 AI 视频生成工具
- **痛点反转六段式**骨架(AI开头→痛点钩子→产品出场→卖点拆解→异议处理→收尾安利),含榜单 / 对比 / 硬广背书变体
- **痛点先行双层执行**:段落级(钩子先铺痛点)+ 卖点级(每个卖点段以「……的痛,你们懂吧?」起手)
- 强第二人称"你"、自问自答节奏、数据必做三级换算、抽象概念必打生活化比方
- 分人群安利 + 金句收尾;华为/荣耀内容自动品牌隔离(不出现其他品牌名)

## 安装

```bash
# Claude Code:放入 skills 目录
git clone https://github.com/<你的用户名>/feibao-unboxing-copywriter.git ~/.claude/skills/feibao-unboxing-copywriter
```

Claude Desktop:设置 → Skills → 上传 `SKILL.md`(或在对话中让 Claude 用 save_skill 保存)。

之后对 Claude 说:「用菲宝风格写一篇关于 XX 的开箱口播稿」即可触发。
